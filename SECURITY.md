
# 🔒 Security Policy

The security of **Omarchy Tweaker** and its users is important to me. I appreciate responsible security research and encourage anyone who discovers a potential vulnerability to report it privately and responsibly.

## 📌 Supported Versions

Omarchy Tweaker is currently maintained as a personal project. Security updates and fixes are provided for the latest available version whenever reasonably possible.

| Version | Supported |
|:---|:---:|
| Latest | ✅ |
| Older versions | ❌ |
| Unmaintained versions | ❌ |

> **Note:** This project does not currently maintain separate release branches or guarantee security updates for older versions.

## 🚨 Reporting a Vulnerability

If you discover a potential security vulnerability, please report it responsibly.

**Please do not disclose security vulnerabilities through public GitHub Issues or discussions.**

Instead, use one of the following methods:

- **GitHub Security Advisories:** [Privately report a vulnerability](https://github.com/Armoghans-Organization/Omarchy-Tweaker/security/advisories/new)
- **Private Contact:** Contact the repository owner through GitHub if private vulnerability reporting is unavailable.

### 📋 What to Include

To help investigate and resolve the issue, please provide:

- A clear description of the vulnerability.
- Steps to reproduce the issue, if applicable.
- The potential impact and affected components.
- Relevant logs, screenshots, or proof-of-concept details.
- Any suggested mitigation or remediation, if available.

### 🔍 Response & Resolution

I will make reasonable efforts to:

1. Acknowledge your report as soon as reasonably possible.
2. Investigate and assess the reported vulnerability.
3. Request additional information if necessary.
4. Develop and verify an appropriate fix where applicable.
5. Communicate the outcome and publish relevant security updates.

Response and resolution times may vary depending on the complexity and severity of the issue, as well as my availability as an individual maintainer.

### 🤝 Responsible Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.

I appreciate responsible security researchers who help make this project safer.

## ⚖️ Scope & Limitations

This security policy covers security vulnerabilities directly related to the code, scripts, configurations, and other resources maintained in this repository.

It does not guarantee security support for:

- Third-party applications, packages, or dependencies.
- The underlying Omarchy or Arch Linux installations.
- User-modified configurations or externally sourced scripts.
- Issues unrelated to this repository.
