## About

Omarchy Tweaker is a personal project focused on customizing, automating, and streamlining my [Omarchy](https://omarchy.org) Installation.

The goal is to bring together useful tweaks, configurations, scripts, and utilities into a single toolkit that makes managing and personalizing my desktop environment easier.

This project is currently in its early stages and is actively being developed.


## Disclaimer

This project is primarily designed for my personal setup. Some operations may modify system configurations, install or remove packages, and change system settings.

Review the scripts before running them and make sure you have appropriate backups. Use at your own risk. I am not responsible for any damage, data loss, or system issues resulting from its use.
